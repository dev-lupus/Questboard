# Questboard

## Ideas
- small questing game in your terminal
- do stuff
  - take on quests
  - buy and upgrade equipment
  - talk to people
  - explore, get treasure, slay enemies
  - rep system, social status, economy

- Directories of the PC are locations in the Game
    - no need for a map, already generated by the distro
    - varied gameplay, custom locations, 
    - file size = difficulty, enemy variations, encounter seed?
    - directory is only queried, not touched
        - everything lives in ~/.local/Questboard
